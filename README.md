# ✦ Aesthetic Collage Studio (AI-Free Photo Collage Maker)

An ultra-refined, deterministic, client-side aesthetic photo collage maker crafted in pure JavaScript and HTML5 Canvas.
**100% Zero Artificial Intelligence** — powered entirely by mathematical coordinate projections, geometric ratio layouts, procedural film grain synthesis, and high-performance Canvas 2D graphics.

Live Website on GitHub Pages: **[https://jmaity434.github.io/aesthetic-collage-maker/](https://jmaity434.github.io/aesthetic-collage-maker/)**

---

## 🌟 Key Highlights & Core Features

1. **Zero Artificial Intelligence (100% Deterministic & Private)**:
   - No external servers, no cloud APIs, and absolutely no generative AI or neural models.
   - Everything runs locally in the user's browser with instant 60 FPS real-time responsiveness.
   - 100% photo privacy: your memories never leave your device.

2. **Up to 20 Photos Dynamic Upload**:
   - Upload any number of photos from **1 to 20 images**.
   - Multi-photo drag & drop file upload zone.
   - Thumbnail strip with individual photo removal (`✕`), re-ordering, and slot counter badge (`X / 20`).
   - Built-in "Load Demo Aesthetic Photos" button to test all 100 styles immediately.

3. **Custom Frame Aspect Ratios**:
   - `4:5` Instagram Feed Portrait
   - `1:1` Square (Instagram Post / Album Sleeve)
   - `9:16` Story / Reels / TikTok / Mobile Wallpaper
   - `16:9` Cinematic Landscape / Desktop Wallpaper / YouTube Banner
   - `3:4` Classic Portrait Photo Print
   - `4:3` Classic Landscape Photo Print
   - `2:3` 35mm Analog Print
   - `3:2` 35mm Horizontal Landscape
   - `21:9` Ultra-wide Panoramic Cinema
   - `A4` International Standard Document & Wall Poster

4. **100 Researched Aesthetic Styles & References Catalog**:
   - Comprehensive library covering 10 distinct design movements with 10 curated styles each (total 100):
     - **Minimalist & Editorial** (Vogue Monograph, Kinfolk Serenity, Swiss Typographic, Tokyo Gallery...)
     - **90s Nostalgia & 35mm Film** (Polaroid 600, 35mm Filmstrip Contact, Kodak Portra, Medium Format 120mm...)
     - **Handcrafted Scrapbook & Journal** (Japanese Washi Tape Grid, Pressed Flora, Moleskine Bullet Journal...)
     - **Modern Bento & Modular Grid** (Apple Bento Matrix, Golden Ratio Fibonacci, Dynamic Masonry, Tetris...)
     - **Dreamy & Lo-Fi Aesthetics** (Instagram Carousel, TikTok Photo Dump, Pinterest Moodboard, Cyberpunk Neon...)
     - **Hero & Small Focus (1-4 Photos)** (Single Hero Solo, Diptych Split, Triptych Horizon, Quad Classic...)
     - **Asymmetric Harmony (5-8 Photos)** (Bento 5, Olympic Rhythm, Sextet 2x3 Wall, Octet Film Matrix...)
     - **Dense Mosaic & Wall (9-16 Photos)** (3x3 Instagram Mosaic, 10-Photo Bento, 12-Photo Proof Sheet...)
     - **Grand Exhibition (17-20 Photos)** (Master Exhibition Wall, 20-Photo Polaroid Scatter, Stamp Sheet...)
     - **Artistic, Print & Ephemera** (Herbarium Specimen, Blueprint Cyanotype, Vinyl Gatefold, Risograph...)

5. **Real-Time Interactive Live Controls**:
   - Live sliders for Frame Gap (`0px - 50px`), Corner Radius (`0px - 40px`), and Outer Margin/Padding (`0px - 80px`).
   - Frame Styles: Clean Minimal, Polaroid Chin, 35mm Filmstrip Sprockets, Museum Passepartout, Floating Shadow.
   - Procedural Film Grain overlay slider (`0% - 45%`).
   - Semi-transparent torn Washi Tape corners with authentic fibrous texture.
   - Classic camera digital date stamp (`'26 10 18`).
   - Editorial serif/sans headline & typography overlay.
   - Interactive cell controls: click cell to Zoom, drag inside cell to Pan, rotate 90°, and flip H/V.

6. **Ultra-HD High-Resolution Export**:
   - `1x` Standard Web
   - `2x` HD (Crisp 1080p+ for Instagram / Pinterest)
   - `4x` Ultra HD (4K Print Ready)
   - Formats: PNG (Lossless) and JPEG.
   - One-click "Copy to Clipboard" support.

## 🛠️ Technology Stack

- **Core**: Vanilla HTML5 & Modern ES6+ JavaScript Modules.
- **Rendering**: HTML5 Canvas 2D Graphic Context (Hardware-accelerated).
- **Styling**: Tailwind CSS + Custom Dark Glassmorphic Design System (`css/style.css`).
- **Typography**: Google Fonts (Cormorant Garamond, Space Grotesk, DM Sans, Playfair Display, Syne, Caveat, VT323).
- **Hosting**: GitHub Pages.

## 🚀 Local Development

To run the application locally without any server dependencies:
```bash
# Using any local static server (Node, Python, or PHP)
npx serve .
# or
python -m http.server 8000
```
Open `http://localhost:8000` or double-click `index.html` in modern browsers that support ES modules.
